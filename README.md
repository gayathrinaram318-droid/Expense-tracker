# 💰 Smart Expense Tracker

A simple and user-friendly web application for tracking income and expenses. It helps users manage their spending, organize transactions by category, and understand their financial activity.

## 🌐 Live Demo

[View Live Website](https://fin-track-15d85c.netlify.app)

## ✨ Features

- Add income and expenses
- Record transaction details
- Categorize transactions
- Calculate total income and expenses
- Track remaining balance
- View spending information using charts
- Monthly spending analysis
- Spending alerts
- Smart spending insights
- Transaction history
- Responsive and user-friendly interface
- Store data using browser Local Storage

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage
- Chart.js

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Start adding your income and expenses.

## 🎯 Purpose

The purpose of this project is to create a simple digital solution for managing personal expenses and understanding spending habits.
